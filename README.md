# Koa Longboards — Static Site

A simple, single-page site ready for GitHub Pages.

## Deploy (super short)
1. Create a repo named `koalongboards` (Public).
2. Upload these files (keep this folder structure):
   - index.html
   - images/ (all images in here)
   - README.md
3. Repo → Settings → Pages → Source: Deploy from a branch → Branch: main /(root) → Save.
4. Visit https://YOUR-USERNAME.github.io/koalongboards/

## Custom domain later
Set a custom domain in Settings → Pages and follow the DNS notes there.
